# Amul Demand Forecasting Project

A case study project focused on forecasting demand for Amul dairy products using historical sales data, manual analysis, and visualization tools like Excel.

## Objective
The objective of this project is to forecast the future demand of Amul dairy products using historical data and analytical techniques. The aim is to help improve inventory planning, production scheduling, and supply chain efficiency.

---

## Tools & Technologies Used
- Microsoft Excel (data cleaning, EDA, and manual forecasting)
- Python (for time series analysis)
- Power BI (interactive dashboards and visualizations)
- GitHub (project version control and collaboration)

---

## Dataset Description
- Data Source: Sample retail sales data from dairy distributors (Amul-focused)
- Time Period: January 2022 to December 2024
- Variables:
  - Product Name
  - Sales Quantity
  - Region
  - Date
  - Inventory Level

---

## Methodology
1. Data Cleaning (missing values, formatting)
2. Exploratory Data Analysis (trend, seasonality)
3. Forecasting Techniques:
   - Moving Average
   - Linear Regression
   - ARIMA (optional via Python)
4. Visualization:
   - Excel Charts
   - Power BI Dashboard

---

## Dashboard & Insights
- Total sales trends (monthly)
- Top performing products
- Region-wise demand heatmap
- Forecast for next 6–12 months


- `reports/Final_Report.pdf` – Project report

---

## Conclusion
This project provides valuable insights into the dairy product demand trends and helps businesses make data-driven decisions for supply chain planning and resource allocation.
